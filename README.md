Arcana Narrativa

Un'applicazione web per la gestione, consultazione ed estrazione casuale di strutture narrative, basata sulle Funzioni di Vladimir Propp e sulle fasi del Viaggio dell'Eroe.

Utilizzo Online

L'applicazione è disponibile all'indirizzo:
https://tagtthespellcaster.github.io/Arcana-Narrativa/

Funzionalità Presenti

Selezione dei mazzi di carte: Funzioni di Propp (31 carte), Viaggio dell'Eroe (12 carte) o mazzo combinato (43 carte).

Modalità di estrazione casuale: carta singola, trittico narrativo (3 carte), percorso completo (4 carte) o estrazione libera a 5 carte.

Animazione di capovolgimento carte con effetto visuale 3D al click.

Enciclopedia interna consultabile con campo di ricerca testuale e filtri per categoria.

Editor integrato per la creazione e il salvataggio locale di carte personalizzate.

Funzionalità di esportazione ed importazione dell'intero mazzo in formato JSON.

Taccuino dello scrittore integrato per la stesura di appunti e storie con salvataggio locale ed esportazione in file .txt.

Guida all'Uso

Aprire l'applicazione tramite browser web.

Dal pannello laterale, scegliere il mazzo desiderato (Mazzo Combinato, Funzioni di Propp o Viaggio dell'Eroe).

Selezionare una modalità di estrazione per distribuire le carte sul tavolo virtuale.

Cliccare sulle carte coperte per girarle e consultare i dettagli narrative e i prompt di scrittura.

Utilizzare i pulsanti "Rivela Tutto" o "Copri Tutto" per gestire simultaneamente le carte stese.

Aprire la sezione "Enciclopedia Carte" tramite la barra di navigazione superiore per cercare carte specifiche.

Utilizzare la sezione "Taccuino" per annotare idee e salvare il testo in formato locale o scaricarlo in file .txt.

Creare nuove carte personalizzate tramite la finestra di creazione ed esportare la configurazione tramite il pulsante "Esporta JSON".
